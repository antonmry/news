- zellij-org/zellij: Release v0.45.1 — This is a small patch release (mostly) set to address some issues discovered in the latest 0.45.0 . Notable changes The nested session detection now works over SSH without having to forward environment variables It's now possible to opt-out of the newly introduced behavior, where scrolling with the mouse inside a pane enters scroll mode. To do so, add scroll_mode_sync false to the configuration. It's now possible to set an explicit theme hue in the config (i.e. dark or light) that will be used if the system doesn't know which theme we're in. To do so, add explicit_theme_hue light # or dark to the config. New feature: it's now possible to start a new session in the foreground or background with a specific running command instead of the default terminal. zellij attach -c foo -- htop for foreground zellij attach -b foo --htop for background.
