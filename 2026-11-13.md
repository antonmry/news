( #61832 ) When a subagent goes idle while its own background work is still running, its report to the parent now says it is still running, so the parent waits for the final report instead of treating the partial answer as done. ( #63675 ) Code Mode gets simpler structured results from file and skill tools: write and edit return their confirmation as a string, patch returns an empty result, and skill returns the skill's directory and content. Bug fixes Restored pasted text when undo brings back its placeholder. Restored the live draft after browsing prompt history. Fixed copying a paste from within the prompt selection. Preserved the Mini composer caret when closing the command palette. Prevented image bytes from being retained in transcript storage when image previews are disabled. Fixed paste-chip contrast across light and dark themes. Fixed plugin-provided themes updating live. Session lists now open at the top rather than at the current session. Mini scrollback now shows the subagent card instead of obsolete launch instructions. Desktop Improvements Added Jump to message to the command palette with Cmd+Alt+G / Ctrl+Alt+G , including prompts not yet loaded in the timeline. Thanks @usrnk1 . ( #63585 ) Added the experimental Recent sessions sidebar, with cross-server recency, local pins, reordering, and standard session-row actions. Recent sessions are limited to the last seven days and 30 rows, and can be hidden or muted. Added an experimental customizable sessions sidebar. Mermaid diagrams can now be maximized for zooming and panning. ( #59250 ) Added Alt+Enter to place a follow-up first in the queue and Mod+Enter to steer the next queued prompt. Holding the modifier key now shows tab shortcut numbers. Each server’s terminal shell can be selected from its menu. Added a free-limit panel in place of the composer when applicable. Session IDs are easier to find and copy. Bug fixes Recent sessions now keep stable recency ordering through list reloads, renames, and completed runs. Fixed browser panes not retrying after server plugins finish loading. Fixed mention suggestions being recreated while typing. Fixed SSH prompts failing to advance or close after connection. Fixed pasted provider-auth redirect URLs being rejected. Restored message footers in the New timeline. Fixed links whose labels contain inline code. Fixed the file-tree sidebar opening animation. Fixed pairing QR-code contrast in light themes. Thanks @ssskay . ( #63220 ) Fixed activity-tab navigation and click handling. Thanks @OpeOginni .
