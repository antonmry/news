( #60647 ) When read misses because a folder is missing, the error names that folder and the nearest one that exists. ( #60694 ) Idle locations no longer restart their MCP servers right after shutting down. ( #60668 ) Compaction now caps its prompt at the model's context window when the input limit is larger. ( #60660 ) LiteLLM context window errors now trigger compaction instead of stopping the session. ( #60498 ) TUI Bug fixes The connect menu no longer lists MCP servers, which are managed in their own place. ( #60675 ) Desktop Improvements Added keyboard shortcuts to choose a worktree and its base branch, shown in tooltips, and a shortcut to toggle shell mode. ( #60640 ) Added flat input surfaces and a compact input size. ( #60598 ) Bug fixes The connect menu no longer lists MCP servers.
