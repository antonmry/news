- rvben/rumdl: v0.3.0 — Changed 2.4–4.7× faster rumdl fmt than 0.2.79 on frozen documentation snapshots: Cargo (99 files) 4.7×, MkDocs Material (85 files) 2.6×, and Ruff (16 files) 2.4×. Reusing parsed Markdown and shared source analysis reduces repeated work. Speedups compare median elapsed times from 31 paired runs after five warmups on Apple M6: ordinary Rust 1.96.0 release builds, default threads, warm filesystem cache, and --no-config --no-cache --silent ( --flavor=standard for Cargo/Ruff, --flavor=mkdocs for MkDocs Material). Output includes the correctness fixes listed below and can differ from 0.2.79. Code block tools are supported and remain opt-in. Missing tags, missing active-mode tools and invocations with no tools checked are ignored by default. An omitted unknown-tag policy inherits on-missing-language-definition , preserving existing strict configurations. Valid internal cached checks count as checked; applicable external tools rerun to reflect changes in their own configuration and environment. on-missing-language-definition = "warn" now reports uncovered languages; previous releases treated it as ignore . Executable lookup remains system-only by default. Per-binary preferences can opt into nearest-first project lookup bounded by repository/configuration boundaries, including hoisted workspace installations. MD037 still reports spaces inside emphasis delimiters but no longer provides automatic fixes, including editor fixes. Repair the reported emphasis manually; inserting escapes or removing whitespace can change literal Markdown meaning. Added fmt --preflight and check --fix --preflight validate and plan the complete selected file batch before applying any writes, with atomic replacement per file after successful planning. Configurable coverage policies with block diagnostics and invocation-wide fail-fast behavior. Invalid tool definitions receive central configuration warnings, made fatal by --deny-config-warnings . Fail-fast tool policies report an incomplete invocation (exit 2), including when document finding failures are disabled with --fail-on never . Shared full-table language recognition and flavor-aware fence coverage. No-tools invocation errors preserve JSON's findings array and use SARIF invocation notifications rather than assigning errors to a document. --stdin-batch-targets FILE supplies a NUL-delimited file/directory inventory for cross-file existence checks without requiring placeholder documents.
